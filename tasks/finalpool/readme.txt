## Task Structure
Each task in this directory follows the standard BenchTasksCollv3 task structure:
- docs/task.md - Task description
- docs/agent_system_prompt.md - Agent system prompt
- docs/user_system_prompt.md - User system prompt (optional)
- evaluation/main.py - Evaluation script
- preprocess/main.py - Preprocessing script (optional)
- groundtruth_workspace/readme.txt - Ground truth workspace (optional)
- initial_workspace/readme.txt - Initial workspace (optional)
- task_config.json - Task configuration with MCP server requirements
